# Dashboard Analytics 💣📊

Dashboard Analytics

A modern and responsive dashboard application built with React, TypeScript, Tailwind CSS, and Vite. The project demonstrates scalable frontend architecture, reusable UI components, data visualization, and type-safe development practices.

Features include analytics dashboards, customer and order management views, interactive charts, responsive layouts, and simulated API workflows powered by structured mock data.

Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Recharts
- Framer Motion
- Lucide React
- date-fns

Highlights

- Reusable component architecture
- Interactive data visualization
- Responsive dashboard design
- Centralized mock data management
- Type-safe interfaces and models
- Simulated API integration
- Modern and scalable frontend structure
